How to Play

Enter a nickname, choose Create Game, select a quiz and share the room code or invite link. Friends can join from another browser or device. Once players are ready, the host starts the match.

Answer each question before the timer runs out. Classic awards points by difficulty; Speed rewards the quickest correct answers; Elimination gives each player three lives. The host controls each round.

Your quizzes are stored only on this browser. Use Export/Import JSON to move them to another device. Keep the hosting tab open during multiplayer games.

Connection note: This game uses peer-to-peer WebRTC via the public PeerJS signaling service. Restrictive networks can prevent connecting, even if the site is online.
